# Prince Task Agent 24/7

Autonomous AI Agent deployed on Render with 24/7 Telegram integration and tool capabilities (Web Search, Web Scraping, Python Execution).

## Features
- 24/7 uptime on Cloud
- Powered by Google Gemini Flash
- Integrated with Telegram Bot (@PrinceTaskAgentBot)
- Autonomous ReAct loop with tools
- Built-in HTTP health check for cloud platform keep-alive
